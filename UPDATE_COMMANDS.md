# Команды для обновления бота на сервере

## Способ 1: Через скрипт обновления

После подключения к серверу выполните:

```bash
# 1. Подключитесь к серверу
ssh root@200.234.239.58

# 2. Перейдите в директорию проекта
cd ~/children_task_tracker

# 3. Скопируйте скрипт обновления (если его нет) или выполните команды вручную:
```

## Способ 2: Команды вручную

Выполните следующие команды на сервере:

```bash
# 1. Подключитесь к серверу
ssh root@200.234.239.58

# 2. Перейдите в директорию проекта
cd ~/children_task_tracker

# 3. Обновите код из репозитория
git fetch origin
git checkout main  # или master, в зависимости от вашей ветки
git pull origin main  # или master

# 4. Остановите контейнеры
docker-compose down

# 5. Пересоберите и запустите контейнеры
docker-compose up -d --build

# 6. Примените миграции (если есть новые)
sleep 5
docker-compose exec bot python -m alembic upgrade head

# 7. Проверьте статус
docker-compose ps

# 8. Просмотрите логи (опционально)
docker-compose logs -f bot
```

## Способ 3: Одной командой (если скрипт уже на сервере)

```bash
ssh root@200.234.239.58 "cd ~/children_task_tracker && ./update.sh"
```

Но для этого нужно сначала загрузить скрипт на сервер.
