# Детский контроллер (Children Check Bot)

Telegram-бот для автоматического контроля выполнения детьми ежедневных заданий (Duolingo, чтение, физкультура и т.д.) с автоматическим подсчётом денежных наград и отправкой отчётов родителям.

## Основные возможности

- 📅 Автоматическая выдача заданий по расписанию
- ⏰ Напоминания каждому ребёнку в нужное время
- ✅ Приём подтверждений выполнения (кнопка + медиа)
- 💰 Автоматический подсчёт наград по индивидуальным ставкам
- 📊 Ежедневные и еженедельные отчёты для админа
- 🚀 Полная автоматизация — родителю не нужно ничего контролировать вручную

## Технологии

- Python 3.11+
- aiogram 3.x (Telegram Bot API)
- PostgreSQL
- APScheduler (планировщик задач)
- Docker

## Быстрый старт

1. Скопируйте `.env.example` в `.env` и заполните переменные окружения
2. Запустите через Docker Compose:
   ```bash
   docker-compose up -d
   ```
3. Примените миграции БД: `alembic upgrade head` (схема БД меняется только миграциями Alembic)
